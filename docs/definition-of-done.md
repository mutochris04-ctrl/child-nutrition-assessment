# Definition of Done

A user story is "Done" only when ALL of the following are true:

1. The code is written and pushed to the main branch on GitHub.
2. The feature meets all of its acceptance criteria in the backlog.
3. Automated tests (pytest) are written for the feature.
4. All tests pass in the GitHub Actions CI pipeline (green tick).
5. The code is readable, with clear names and short comments where needed.
6. The README or docs are updated if the feature changes how to use the service.
7. The feature has been shown in the Sprint Review.
